# Dotfiles review, 2026-11-07

A six-area review after the move to Strand and Kitty: 85 findings, each checked by a second agent, all
worked through the same day, and Quickshell, Ghostty, pane-fm and cliphist retired with them. The
full findings, with evidence and per-item status, are in git at `e52d2eb`
(`git show e52d2eb:docs/review-2026-11-07.md`). What's below is what a later review should know:
what was decided against, and what's still open.

## Decided: don't raise again

- **Notifications.** A newer notification replacing the one showing is by design, and so is a click
  closing a card with nothing to open: notification history keeps it. The island's bell means "not
  yet cleared", not "unread".
- **No low-battery notifications.** The glyph's warning and danger tints are enough.
- **Files owned by another tool stay out of chezmoi:** `monitors.lua` (Strand writes it),
  `mimeapps.list`, `~/.ssh/config`. Monitor profiles are the exception since 2026-11-08: hyprpier
  is gone, and Strand's `monitors.toml` lives in the source (`state/`, linked into
  `~/.config/strand/`) so the profiles are versioned with the rest; the Displays page writes it there. Folders reach Yazi through Kitty's `launch-actions.conf` instead
  of the folder handler.
- **Thunderbolt: one Enter allows a waiting device always** (2026-11-08), as the owner decided and
  like the Bluetooth pairing ask, which also opens the launcher by itself. A second Enter to confirm
  was built first, against a stray Enter landing in the ask, and dropped.
- **Page keys.** Only clipboard (Super+V), the power key and the urgent window (Super+U) are bound;
  every other launcher page is Alt and a letter once it's open.
- **Screens off at 30 minutes, behind a 10-minute lock,** so the lock screen stays visible. Keep
  awake covers long reads and talks.
- **The GPU prompt, branches and symlink script stay** for a reinstall on other hardware; the prime
  branch uses the symlinks.
- **Light palettes keep upstream's own colours** where upstream is merely pale (Latte's black,
  yellow and pink in Kitty). Everforest Light's terminal and Dawn's black were darkened because they
  were unreadable.
- **Not done, and fine:** splitting launcher.strand by concern (revisit if it keeps growing), a
  1Password Quick Access window rule (nothing opens it on Wayland), idle-inhibit on fullscreen (the
  apps inhibit themselves).

## Open

- **Monitors cutover from hyprpier** (2026-11-08, `docs/strand-shell/features.md`), in this order:
  Strand `d9d726f4` or later and a restart of it; `chezmoi apply` (its retire script stops
  `hyprpier daemon`, removes hyprpier's `monitors.lua`, which Strand refuses to write over until then, and with sudo its resume service and udev
  rule; the Thunderbolt script installs `thunderbolt-resume.service`); then, docked, Alt+H and Enter
  to let the WD19TB in always (hyprpier's rule let it in without bolt storing it), and
  `yay -R hyprpier-git`. At work, check the first dock lands as the work profile says (its ids
  come from hyprpier's profile, never seen by Strand; Enter on the Displays page saves the layout
  if not), and allow that dock the same way if it is a different one. The resume service is
  untested across a real suspend: after one with the dock attached, its USB devices should be back
  and `journalctl -b -u thunderbolt-resume` should not say "not let back in" (it waits up to 30 s
  for bolt to let each stored device back in before the replug).

- **arch-quickstart's package lists** predate Strand and Kitty, so a fresh install misses kitty,
  Strand, wf-recorder, libqalculate, qt5ct and adw-gtk-theme. Deferred; the README lists what to
  add by hand meanwhile.
- **Light-palette accents** (taste): Latte's sapphire and Everforest Light's green are under 3:1
  as text. Each palette's `_accent` is a one-line change.
- **/etc/pam.d/strand,** so a faillock lockout shows its own message rather than "Wrong password"
  ahead of it. Try it in the lock VM first: under `requisite` it can loop.
- **The docked suspend re-test** (`dot_config/hypr/README.md`), then restore or date the decision.
- **New README screenshots.**
- **~/.ssh/config:** the railway block's `IdentityAgent none` never applies, because `Host *` comes
  first. Move the railway block above it.
