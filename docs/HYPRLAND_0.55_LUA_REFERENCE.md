# Hyprland Lua Configuration — Complete Surface Area

> Reference doc for the 0.55 hyprlang → Lua migration. See `HYPRLAND_0.55_MIGRATION.md` for the project-specific port checklist.

Since Hyprland 0.55, the old hyprlang syntax is deprecated. Config lives at `~/.config/hypr/hyprland.lua` (override with `--config`/`-c`). Lua stdlib is loaded; `require()` is recommended (each required file is its own scope so errors are isolated). Config auto-reloads on save (or `hyprctl reload`). Emergency keybinds if config breaks before binds load: `SUPER+Q` (terminal), `SUPER+R` (run), `SUPER+M` (exit). LSP stubs ship at `/usr/share/hypr/stubs/`.

Below is the complete API surface organized by category.

## 1. Core entrypoints

`hl.config({ ... })` — set all options. Top-level subtables:

`general`, `general.snap`, `decoration`, `decoration.blur`, `decoration.shadow`, `decoration.glow`, `animations`, `input`, `input.touchpad`, `input.touchdevice`, `input.virtualkeyboard`, `input.tablet`, `gestures`, `group`, `group.groupbar`, `misc`, `layout`, `binds`, `xwayland`, `opengl`, `render`, `cursor`, `ecosystem`, `quirks`, `debug`, plus layout-specific: `dwindle`, `master`, `scrolling`.

Variable types: `int`, `bool`, `float`, `color` (web hash `#fafc21`, `rgba(...)`, `rgb(...)`, legacy `0xAARRGGBB`), `vec2` (`{20,20}`), `str`, `gradient` (color or `{ colors = {"rgba(...)", ...}, angle = 45 }`), `font_weight` (100–1000 or `thin|ultralight|light|semilight|book|normal|medium|semibold|bold|ultrabold|heavy|ultraheavy`), `css_gaps` (int or `{ top?, left?, right?, bottom? }`).

Also at the top level: `hl.config({ autogenerated = true })` — remove this line to dismiss the yellow warning on the autogenerated default config.

## 4. Binds — `hl.bind`, `hl.unbind`, submaps

`hl.bind(keys, dispatcher_or_fn, flags?)` where `keys` is `"MOD + KEY"` (empty mod allowed). Keys can be `code:NN` (keycode), `mouse:NNN`, `mouse_up`/`mouse_down`/`mouse_left`/`mouse_right`, `switch:[name]` / `switch:on:[name]` / `switch:off:[name]`, or `catchall`.

Dispatcher arg can be a dispatcher table (from `hl.dsp.*`) or a `function()` calling `hl.dispatch(hl.dsp...)`.

Flags table keys: `locked`, `release`, `click`, `drag`, `long_press`, `repeating`, `non_consuming`, `auto_consuming`, `mouse`, `transparent`, `ignore_mods`, `separate`, `description`, `bypass`, `submap_universal`, `devices = { inclusive = bool, list = {...} }`.

`hl.unbind("SUPER + O")` — case-sensitive; matches the exact case of the original bind.

Mouse-specific bind helpers (use `{ mouse = true }` flag): `hl.dsp.window.drag()`, `hl.dsp.window.resize()`. LMB=272, RMB=273, MMB=274.

### Submaps

```lua
hl.bind("ALT + R", hl.dsp.submap("resize"))
hl.define_submap("resize", function() ... end)
-- with auto-exit:
hl.define_submap("submapA", "submapB", function() ... end)  -- after dispatch, go to submapB
hl.define_submap("submapB", "reset", function() ... end)    -- after dispatch, exit
```

Use `hl.dsp.submap("reset")` to leave. `catchall` keysym matches any key.

## 5. Dispatchers — `hl.dsp.*` (used inside `hl.bind` or `hl.dispatch(...)`)

Parameter conventions:

- `action`: `"toggle"` (default), `"enable"`/`"on"`, `"disable"`/`"off"`
- `window`: object | `class:RE` | `initialclass:RE` | `title:RE` | `initialtitle:RE` | `tag:NAME` | `pid:N` | `address:0x...` | `activewindow` | `floating` | `tiled`
- `workspace`: object | ID | workspace selector (see §5.1)
- `direction`: `l`/`r`/`u`/`d`
- `monitor`: object | ID | direction | name | `desc:...` | `current` | `relative:+1/-2`

### General — `hl.dsp.*`

`exec_cmd(cmd, rules?)`, `exec_raw(cmd)`, `focus({direction})`, `focus({monitor})`, `focus({workspace, on_current_monitor?})`, `focus({window})`, `focus({urgent_or_last})`, `focus({last})`, `exit()` (prefer `hyprshutdown`), `submap(name)`, `pass({window?})`, `send_shortcut({mods, key, window?})`, `send_key_state({mods, key, state, window?})`, `layout(message)`, `dpms({action?, monitor?})`, `event(string)` (socket2), `global(string)` (dbus global shortcut), `force_idle(seconds)`, `no_op()`.

### Window — `hl.dsp.window.*`

`close(window?)`, `kill(window?)`, `signal({signal, window?})`, `float({action?, window?})`, `fullscreen({mode?, action?, window?})` (mode = `"maximized"`|`"fullscreen"`), `fullscreen_state({internal, client, action?, window?})` (-1 current, 0 none, 1 maximize, 2 fullscreen, 3 maximize+fullscreen), `pseudo({action?, window?})`, `move({direction})`, `move({workspace, follow?})`, `move({monitor, follow?})`, `move({x, y, relative?})`, `move({into_group = direction})`, `move({into_or_create_group = direction})`, `move({out_of_group})`, `swap({direction})`, `swap({target})`, `swap({next})`, `swap({prev})`, `center({window?})`, `cycle_next({next?, tiled?, floating?, window?})`, `tag({tag, window?})`, `clear_tags({window?})`, `toggle_swallow()`, `pin({window?})`, `alter_zorder({mode, window?})` (`"top"`/`"bottom"`), `set_prop({prop, value, window?})`, `deny_from_group({action?})`, `drag()`, `resize()`, `resize({x, y, relative?, window?})`, `bring_to_top()`.

### Workspace — `hl.dsp.workspace.*`

`rename({workspace, name?})`, `move({workspace?, monitor})`, `swap_monitors({monitor1, monitor2})`, `toggle_special(special_name)`.

### Group — `hl.dsp.group.*`

`toggle({window?})`, `next({window?})`, `prev({window?})`, `active({index, window?})`, `move_window({forward?, window?})`, `lock({action?, window?})`, `lock_active({action?})`.

### Cursor — `hl.dsp.cursor.*`

`move_to_corner({corner, window?})` (corner 0–3), `move({x, y})`.

### 5.1 Workspace selectors

`1`, `+1`/`-3`/`+100`, `m+1`/`m-2`/`m~3` (per-monitor), `r+1`/`r~3` (per-monitor incl. empty), `e+1`/`e-10`/`e~2` (open), `name:Web`, `previous` / `previous_per_monitor`, `empty`/`emptym`/`emptyn`/`emptynm`, `special` / `special:name`. Numeric IDs allowed only 1–2147483647.

### 5.2 setprop

Used with `hl.dsp.window.set_prop({ prop, value, window? })`. Props are any dynamic window-rule effects (see §10). Expanded variants: `border_color` → `active_border_color`, `inactive_border_color`; `opacity` → `opacity`, `opacity_inactive`, `opacity_fullscreen`, plus `*_override` variants.

### 5.3 fullscreen_state value matrix

Values for `internal` and `client`: -1 current, 0 none, 1 maximize, 2 fullscreen, 3 maximize+fullscreen. E.g. `{internal=2, client=0}` fullscreens the window but tells the app it isn't.

## 6. Animations — `hl.animation()` & `hl.curve()`

`hl.animation({ leaf, enabled, speed, bezier|curve|spring, style? })`

- `speed`: in deciseconds (1 = 100 ms)
- `style` per leaf

Animation tree (inherits parent): `global` → `{ windows (slide/popin/gnomed) → windowsIn/Out/Move; layers (slide/popin/fade) → layersIn/Out; fade → fadeIn/Out/Switch/Shadow/Dim/Layers(In/Out)/Popups(In/Out)/Dpms; border; borderangle (once/loop); workspaces (slide/slidevert/fade/slidefade/slidefadevert) → workspacesIn/Out; specialWorkspace (+In/+Out); zoomFactor; monitorAdded }`.

Style suffixes:

- `popin` accepts `"popin 80%"` (start percent)
- workspace slides accept `"slidefade 20%"`
- `slide` accepts forced side: `"slide left|right|top|bottom"`

Curves:

- `hl.curve(NAME, { type = "bezier", points = {{X0,Y0},{X1,Y1}} })`
- `hl.curve(NAME, { type = "spring", mass = M, stiffness = S, dampening = D })`

## 7. Gestures — `hl.gesture({...})`

Fields: `fingers` (2–9), `direction` (`swipe`/`horizontal`/`vertical`/`left`/`right`/`up`/`down`/`pinch`/`pinchin`/`pinchout`), `action` (string or function), `mods`, `scale`, `disable_inhibit`, plus action-specific extras.

Actions: `workspace`, `move`, `resize`, `special` (+ `workspace_name`), `close`, `fullscreen` (+ `mode = "maximize"`), `float` (+ `mode = "float"|"tile"`), `cursor_zoom` / `cursorZoom` (+ `zoom_level`, `mode = "mult"|"live"`), `scroll_move`, lua function/lambda, or `"unset"` to remove a previously defined gesture (must match every field exactly).

## 8. Devices — `hl.device({...})`

Per-device override using name from `hyprctl devices`. Accepts any `input.*` option except `force_no_accel` and window-management options (`follow_mouse`, etc.). Extras:

- `enabled` (mice/touchpads/touchdevices/keyboards)
- `keybinds` (devices sending key events)
- `tags` (keyboards/pointers; comma-separated; used by per-device bind `devices` flag)

## 9. Permissions — `hl.permission({...})`

Requires `hl.config({ ecosystem = { enforce_permissions = true } })`. Changes need restart, not just reload.

`hl.permission({ binary, type, mode })`:

- `binary`: absolute path regex
- `type`: `screencopy`, `plugin`, `keyboard`, `cursorpos`
- `mode`: `allow`, `ask`, `deny`

Defaults: `screencopy = ask`, `plugin = ask`, `keyboard = allow`, `cursorpos = ask`.

## 10. Window & Layer Rules

### `hl.window_rule({ name?, match = {...}, <effects...> })`

Returns a handle with `:set_enabled(bool)` and `:is_enabled()` (named rules only — named rules also evaluate before anonymous ones).

Match props: `class`, `title`, `initial_class`, `initial_title` (all RegEx, prefix `negative:` to invert), `tag`, `xwayland`, `float`, `fullscreen`, `pin`, `focus`, `group`, `modal`, `fullscreen_state_client`, `fullscreen_state_internal`, `workspace`, `content` (`none`/`photo`/`video`/`game`), `xdg_tag`.

Static effects (evaluated once at open): `float`, `tile`, `fullscreen`, `maximize`, `fullscreen_state` (e.g. `"1 2"`), `move` (`{X,Y}` or expression strings), `size`, `center`, `pseudo`, `monitor`, `workspace` (suffix ` silent`), `no_initial_focus`, `pin`, `group` (`"set"`/`"new"`/`"lock"`/`"barred"`/`"deny"`/`"invade"`/`"override"`/`"unset"`, with optional `always`), `suppress_event` (space-separated: `fullscreen maximize activate activatefocus fullscreenoutput`), `content`, `no_close_for`, `scrolling_width`.

Move/size expression vars (space-separated, no inner spaces): `monitor_w`, `monitor_h`, `window_x`, `window_y`, `window_w`, `window_h`, `cursor_x`, `cursor_y`.

Dynamic effects (re-evaluated on change; settable via setprop): `persistent_size`, `no_max_size`, `stay_focused`, `animation`, `border_color`, `idle_inhibit` (`none`/`always`/`focus`/`fullscreen`), `opacity` (e.g. `"0.9 0.7"`, append ` override` to make absolute), `tag` (prefix `+`/`-` or none to toggle), `max_size`/`min_size`, `border_size`, `rounding`, `rounding_power`, `allows_input`, `dim_around`, `decorate`, `focus_on_activate`, `keep_aspect_ratio`, `nearest_neighbor`, `no_anim`, `no_blur`, `no_dim`, `no_focus`, `no_follow_mouse`, `no_shadow`, `no_shortcuts_inhibit`, `no_screen_share`, `no_vrr`, `opaque`, `force_rgbx`, `sync_fullscreen`, `immediate`, `xray`, `render_unfocused`, `scroll_mouse`, `scroll_touchpad`, `confine_pointer`.

### `hl.layer_rule({ name?, match = { namespace = RE }, <effects...> })`

Effects: `no_anim`, `blur`, `blur_popups`, `ignore_alpha` (0–1), `dim_around`, `xray`, `animation`, `order` (int, can be negative), `above_lock` (0/1/2), `no_screen_share`. Also returns a handle with `:set_enabled`/`:is_enabled`.

Opacity is multiplied by default (active_opacity × per-window opacity). Add ` override` per value to force absolute.

## 11. Workspace Rules — `hl.workspace_rule({ workspace, ... })`

`workspace` accepts an ID, a name, or a workspace selector. Selectors can match existing workspaces with props (space-separated): `r[A-B]` (range), `s[bool]` (special), `n[bool]`/`n[s:str]`/`n[e:str]` (named), `m[monitor]`, `w[(flags)A-B]`/`w[(flags)X]` (window count; flags: `t` tiled, `f` floating, `g` count groups, `v` visible, `p` pinned), `f[-1|0|1|2]` (fullscreen state).

Rules: `monitor`, `default` (bool), `gaps_in`, `gaps_out`, `border_size`, `no_border`, `no_shadow`, `no_rounding`, `decorate`, `persistent`, `on_created_empty` (command), `default_name`, `layout`, `animation`, plus layout-specific `layout_opts = { ... }` (e.g. `{ orientation = "top" }` for master, `{ direction = "right" }` for scrolling).

### Scrolling — `hl.config({ scrolling = { ... } })`

### Monocle

No config. Use layout messages: `cyclenext`, `cycleprev`. Note: `hl.dsp.window.cycle_next()` doesn't work here — use `hl.dsp.layout("cyclenext")` or `hl.dsp.window.cycle_next("tiled")`.

### Custom Layouts — `hl.layout.register(name, {...})`

```lua
hl.layout.register("columns", {
  recalculate = function(ctx)
    local n = #ctx.targets
    if n == 0 then return end
    for i, target in ipairs(ctx.targets) do
      target:place(ctx:column(i, n))
    end
  end,
})
```

Use as `lua:columns` (e.g. `general.layout = "lua:columns"` or workspace rule `layout = "lua:columns"`).

The `ctx` arg exposes: `area` (work area), `targets` (list of placement targets), and helpers `ctx:grid_cell(...)`, `ctx:column(i, n)`, `ctx:row(i, n)`, `ctx:split(...)`. Each target has `target:place(box)` (preferred — handles gaps, pseudotiling, reserved area) and `target:set_box(box)` (raw). Targets may expose a `.window` field but it isn't guaranteed (e.g. groups expose only the main one). Optional second arg `layout_msg?` registers a custom message handler.

## 17. Environment & XWayland

`hl.env(KEY, VALUE)` — sets env vars before display server init.

Hyprland-specific: `HYPRLAND_TRACE`, `HYPRLAND_NO_RT`, `HYPRLAND_NO_SD_NOTIFY`, `HYPRLAND_NO_SD_VARS`, `HYPRLAND_CONFIG`.

Aquamarine: `AQ_TRACE`, `AQ_DRM_DEVICES` (colon-separated card paths, first = primary), `AQ_FORCE_LINEAR_BLIT`, `AQ_MGPU_NO_EXPLICIT`, `AQ_NO_MODIFIERS`, `AQ_NO_ATOMIC`.

XWayland HiDPI: combine `hl.config({ xwayland = { force_zero_scaling = true } })` with toolkit env vars (`GDK_SCALE`, `XCURSOR_SIZE`, etc.). `xwayland.create_abstract_socket` toggles the Linux abstract Unix socket for sandboxing.

uwsm users: put env vars in `~/.config/uwsm/env` / `~/.config/uwsm/env-hyprland` instead of `hyprland.lua`.

## 18. Multi-GPU

Detect GPUs with `lspci -d ::03xx` and `ls -l /dev/dri/by-path`. Pick devices with `hl.env("AQ_DRM_DEVICES", "/dev/dri/card0:/dev/dri/card1")` — first path is primary renderer. Avoid `/dev/dri/card*` paths directly (they're reassigned at boot); use udev rules to make stable `/dev/dri/<name>` symlinks.

## 19. Tearing

Master toggle `general.allow_tearing = true`, then add per-game `hl.window_rule({ match = { class = "cs2" }, immediate = true })`. Only effective when the game is the only thing visible on its monitor (fullscreen).

## 20. `hyprctl` for live driving

- `hyprctl eval 'hl.dispatch(hl.dsp.focus({ workspace = "3" }))'` — run arbitrary Lua
- `hyprctl dispatch '<dispatcher>'` — shorthand for `eval 'hl.dispatch(...)'`
- `hyprctl reload`, `kill`, `setcursor <theme> <size>`, `output create|remove [backend] [name]` (backends: `wayland`, `headless`, `auto`), `switchxkblayout <device> <next|prev|N>`, `seterror "<color>" <msg>` / `seterror disable`, `getprop <window> <prop>`, `notify <icon> <ms> <color> <msg>` (supports `fontsize:N`), `dismissnotify [N|-1]`.

Flags: `-j` JSON, `-i` instance, `-r` refresh after, `--batch` for `;`-separated calls.

## 21. Error behavior recap

- Fundamental Lua syntax errors → reload blocked, error popup.
- Runtime Lua errors → abort current file's execution, popup (this is why `require()` separates scopes).
- Hyprland type errors at runtime → continue, popup.
- Async errors (e.g. inside keybind funcs) → notification.
- Infinite loops / reentrant events are killed by a watchdog after a timeout.
- Emergency binds if your config breaks before binds load: `SUPER+Q` terminal, `SUPER+R` run, `SUPER+M` exit.

## 22. Performance quick wins

- Prefer integer monitor scales (fractional Wayland scaling still imperfect).
- Disable `decoration.blur.enabled` and `decoration.shadow.enabled` for battery.
- On Intel iGPU + TLP: raise `INTEL_GPU_MIN_FREQ_ON_AC`/`INTEL_GPU_MIN_FREQ_ON_BAT` in `/etc/tlp.conf`.
- For misbehaving Proton games, run them under `gamescope`.
