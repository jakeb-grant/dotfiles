# Archive

History, not current state. These describe the desktop before Strand and Kitty
(Quickshell, Ghostty, pane-fm, phylax, the Jinja theme pipeline) and the reviews
and plans of that time. They're kept for the record of how choices were made:
`docs/strand-shell/features.md` cites the catalogues and strand-offers, and a
review can check here before raising something already decided.

- `design-review-backlog.md`, `ux-backlog.md`, `scripts-review.md`: closed reviews
- `HYPRLAND_0.55_MIGRATION.md`: the move to the Lua config (done)
- `HYPRLAND_0.55_LUA_REFERENCE.md`: the 0.55 Lua API; the installed stubs in
  /usr/share/hypr/stubs are the current reference
- `catalogue-quickshell.md`, `catalogue-desktop.md`, `strand-offers.md`: the
  scoping for the switch to Strand
